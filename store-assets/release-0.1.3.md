# 履歴: Sift 0.1.3 の更新提出

## 提出するファイル

`.output/store/sift-0.1.3-chrome.zip` を使用します。

2026年9月7日に生成・検査したZIPのSHA256:

```text

```

## 変更点

Xのピン留めリストで絞り込みを開始して引用元を開くと、画像なしの引用元まで非表示になる問題を修正しました。詳細URLが指す当該投稿を表示し、返信やリスト上の絞り込みは維持します。

絞り込みによってセルフリプの続きが隠れたときに、接続線が次の無関係な投稿へ続いて見える問題を修正しました。絞り込み中は接続線を隠し、解除すると元に戻します。

[PR #131](https://github.com/apricot-cake/sift/pull/131)の依存更新を含みます。Lucideを1.34.0、Biomeを2.5.11、Nodeの型定義を26.4.0、React DOMの型定義を19.2.5、happy-domを20.11.12、Viteを8.2.2、Vitestを4.1.11へ更新しました。Biomeの設定スキーマも2.5.11に合わせています。

## 検査結果

更新後の型検査、全241件のテスト、整形・静的解析が成功しました。ZIP内の19ファイルは、提出用ビルド出力とすべて一致しています。生成マニフェストのバージョンは0.1.3、権限はstorageとsidePanelです。ローカル専用の公開鍵、ネイティブメッセージング権限、自己再読み込み処理が提出物に含まれないことも検査しました。

## 更新提出の手順

[Chrome公式の更新手順](https://developer.chrome.com/docs/webstore/update)に従い、既存のSiftの「パッケージ」からZIPをアップロードします。バージョンが0.1.3と表示されることを確認し、既存の公開範囲・地域・公開タイミングを維持して審査へ提出します。審査中も公開済みの0.1.2は利用できます。

掲載文や画像は今回の修正では変更していません。この作業ではストアへのアップロードと審査提出は行っていません。

# Sift 0.1.1 の再提出

## 提出するファイル

`npm run zip:store` で生成する `.output/store/sift-0.1.1-chrome.zip` を使用します。

2026年9月5日に検査した ZIP の SHA256:

```text
8880F011E39FCD327CE597F14530196794775FF16A8F1F2ECFDBD0899A760D15
```

掲載説明と権限の理由は [listing.md](listing.md)、掲載画像は [日本語](screenshots/sift-overview-ja.png)と[英語](screenshots/sift-overview-en.png)を使用します。

## 変更点

- フィルター有効時の幅変更や一時的な画面の開閉で、見ていた投稿の位置を復元します。
- Bluesky で投稿詳細からリストへ戻る際、最上部に戻ってしまう問題を修正しました。
- 条件に合う投稿に付けていた青い強調線を削除しました。

## 検査結果

整形・型検査と全233件のテストが成功しました。生成マニフェストのバージョンは `0.1.1`、権限は `storage` と `sidePanel` です。ストア提出物にローカル用の公開鍵、ネイティブメッセージング権限、自己再読み込み処理は含まれません。ZIP 内の全19ファイルとビルド出力のハッシュが一致しています。

## ダッシュボードでの操作

[Chrome 公式の更新手順](https://developer.chrome.com/docs/webstore/update)に従い、既存の Sift の「パッケージ」から新しい ZIP をアップロードします。表示されたバージョンが `0.1.1` であることを確認し、掲載画像を更新してから審査へ提出します。既存の公開範囲・地域・公開タイミングも確認します。

この準備では、ダッシュボードへのアップロードと審査への提出は行っていません。

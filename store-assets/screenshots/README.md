# 掲載用スクリーンショット

掲載画像は、X・Blueskyでイラストを探すSNSイラストフィルターという用途と、現行の操作欄に合わせて用意します。動画サイトを含む旧画像は削除しました。

## SNSの操作デモ

[sift-demo-social-before-ja.png](sift-demo-social-before-ja.png)と[sift-demo-social-after-ja.png](sift-demo-social-after-ja.png)は、架空の投稿を使った操作デモです。2026年10月18日に更新後の紹介ページを、ウィンドウを表示しない開発用Chromeで撮影しました。表示倍率80%、画像サイズ1280×800ピクセルです。見出しは「いつものタイムラインで、人気のイラストを」です。本文から縦横比の条件を削除し、読み込み済み投稿を対象とする現行の説明へ更新しました。指定なしでは6件、最低いいね数100では124・108いいねの2件が残ることを確認しました。この画像は実サイトの互換性検証として扱いません。

## 画像の確認

画像を開いて、文字の読みやすさ、説明文、表示された投稿と条件の一致を確認します。撮影後は対象タブを閉じ、拡張機能の設定を復元します。

1280×800は[Chrome ウェブストアの掲載画像仕様](https://developer.chrome.com/docs/webstore/images#screenshots)に合わせています。

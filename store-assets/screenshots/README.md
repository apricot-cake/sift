日本語掲載画像は次の4枚を使う。ブラウザの表示倍率は100%。ページと実際の Sift サイドパネルを別々に取得し、横に並べて縦横比を保ったまま1280×800ピクセルの PNG に収めている。余白は白で埋めている。

## X の架空投稿デモ

2026年10月4日に、[掲載画像用 HTML](demo-x.html) と実際の Sift 操作欄を、ウィンドウを表示しない開発用 Chrome で撮影した。3つの架空アカウントに各2投稿を用意し、投稿画像は6色の単色塗りつぶしにした。名前、本文、反応数は作成したサンプルであり、画面にも架空投稿のデモと表示している。

絞り込みには実際の拡張機能を使った。指定なしでは6件、最低いいね数10万では12万・15万・11万の3件が残る。画面内には前後とも複数アカウントの投稿を収めている。この画像は操作の説明用であり、実際の X サイトとの互換性を示す実機検証には使わない。

## YouTube の実ページ

2026年10月4日に `https://www.youtube.com/@Houkaistarrail_jp/videos` を撮影した。サイト側の「新しい順・人気の動画・古い順」も収めている。前後で同じチャンネルを使い、条件による非表示理由を実ページで確認した。数値は撮影時点のもの。

撮影時だけログインユーザーのアカウント表示を不透明なグレーで覆った。公式チャンネルのアイコン、サムネイル、動画タイトル、再生数と Sift の操作欄は残している。動画の追加やタイトルの置換は行っていない。

## 画像の確認

画像を開いて、文字の読みやすさと複数アカウントの構成を確認する。撮影後は対象タブを閉じ、拡張機能の設定を復元する。画像取得後の加工は描画領域の結合とサイズ調整のみで、画像生成 AI は使っていない。

1280×800は[Chrome ウェブストアの掲載画像仕様](https://developer.chrome.com/docs/webstore/images#screenshots)に合わせている。既存の `sift-overview-ja.png` と `sift-overview-en.png` は以前の提出資料である。

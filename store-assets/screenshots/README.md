# 掲載用スクリーンショット

2026年10月4日に開発用 Chrome の実ページと、実際に開いた Sift サイドパネルを CDP で撮影した。サイトとパネルの描画領域を別々に取得し、横に並べて1280×800ピクセルの PNG に整えた。画面や投稿を生成・差し替えたものではない。

## 現在の日本語掲載画像

| 対象 | 絞り込み前 | 絞り込み後 | 確認した変化 |
| --- | --- | --- | --- |
| X の固定リスト「オタク」 | [指定なし](sift-x-before-ja.png) | [最低いいね数500](sift-x-ja.png) | 331いいねの投稿が消え、762いいねの投稿が残る |
| YouTube のブルーアーカイブ公式チャンネル | [指定なし](sift-youtube-before-ja.png) | [最低再生回数10万](sift-youtube-ja.png) | 4.1万・6.5万・9.8万回などの動画が消え、13万・15万・26万・35万回の動画が残る |

前後で同じリスト・チャンネルを使い、条件による非表示理由も実ページで確認した。数値は撮影時点のもの。読み込み済み件数はスクロールに伴って増えるため、前後の件数だけから除外数を判断しない。

撮影時だけ一時的な CSS を適用し、投稿者のアイコン、投稿画像・動画、リンク先の画像、サムネイル、チャンネルのバナー・アイコン、ログインユーザーのアカウント表示を不透明なグレーで覆った。名前、本文、動画タイトル、反応数・再生数、日時、Sift の操作欄は残している。投稿の追加や本文の置換は行っていない。

画像を開いてマスク漏れと文字の読みやすさを確認した。撮影後は対象タブを閉じ、拡張機能の設定を復元した。加工は描画領域の結合とサイズ調整のみで、画像生成 AI は使っていない。

1280×800は[Chrome ウェブストアの掲載画像仕様](https://developer.chrome.com/docs/webstore/images#screenshots)に合わせている。既存の `sift-overview-ja.png` と `sift-overview-en.png` は以前の提出資料であり、今回の更新版では上記4枚を使う。

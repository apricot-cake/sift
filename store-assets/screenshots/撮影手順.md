# X の架空投稿デモの撮影手順

X が表示した投稿の DOM を使い、表示内容を架空のデータに差し替えて撮影する。投稿欄や操作アイコンを別の HTML で再現しない。Sift のサイドパネルと絞り込みには実際の拡張機能を使う。

この手順は掲載用デモの作成に限る。架空投稿での絞り込み結果を、実際の X との互換性を確認した実機検証として扱わない。

## 撮影条件

- 開発用 Chrome を `--headless=new` で起動する。起動から終了までウィンドウを前面に出さず、他のアプリのフォーカスを奪わない。
- 接続先は撮影用に起動した Chrome のローカル CDP だけとする。待受は `127.0.0.1`、ポートは自動割り当てにする。日常プロファイルは使わない。
- 開発プロファイルを使う Chrome が起動している場合は、終了してから撮影する。
- 検証済みの候補パッケージを読み込み、撮影前の拡張機能設定を保存する。
- X の表示倍率は 100%。画像は 2 倍の描画解像度で取得し、最後に一度だけ縮小する。

今回の配置では、Chrome のウィンドウ寸法を 1290×913 に設定した。サイドパネルを開いた後のページ描画領域は 888×776、パネル本体は 360×736 だった。Chrome の版などで変わるため、再撮影時は実際の寸法を取得する。

## 元になる投稿を選ぶ

1. X のホームを開き、固定したリストのタブへ切り替える。
2. Sift のサイドパネルを開き、X の配置がパネル幅に合わせて変わるまで待つ。配置が確定する前に DOM を固定しない。
3. 元から丸いアイコンを使っている個人アカウントの投稿を探す。画像が 1 枚で、リポストの表示がない投稿を選ぶ。見つからなければスクロールして探す。
4. アイコンが丸いことは、画像を包む要素の表示寸法と算出済みの角丸で確認する。四角い組織アカウントの投稿を選び、角丸を上書きして代用しない。

画像が複数ある投稿を元にすると、差し替え漏れやレイアウトの違いが生じるため、この構成では使わない。

## 表示内容を差し替える

X の再描画で内容が戻らないよう、描画済み DOM の複製を撮影用に固定する。X のスタイルには CSSOM へ挿入された規則があるため、`cloneNode` だけでは見た目を保存できない。各スタイルシートの `cssRules` を複製側のスタイル要素へ転記し、描画規則を維持する。

元投稿の DOM を複製し、名前・ハンドル・日時・本文・アイコン画像・投稿画像・反応数を差し替える。名前欄や操作欄を作り直さず、既存要素の文字や画像を更新する。アイコンの形、X のフォント、ナビゲーション、投稿の操作アイコンは元の表示を使う。Lucide などの別アイコンへ置き換えない。

投稿画像は架空アカウントごとに異なる単色画像にする。画像の縦横比は 16:4 とし、X の比率スペーサーも画像に合わせる。元画像の URL と背景画像を両方差し替え、複数画像や引用投稿の内容が残っていないことを確認する。

元投稿の認証バッジ、長い本文に付く「さらに表示」、リポスト元の表示を残さない。インプレッション表示は除く。今回の掲載構成では X のロゴも除いている。

固定リストの表示名を「イラスト」にし、次の 6 投稿を並べる。投稿は X に送信せず、撮影用ページ内の表示だけを変更する。

| --- | --- | --- | --- | ---: | ---: | --- |
| 1 | そら | @sora_draw | 青い朝 | 2,400 | 310 | `#9fd2ea` |

## 絞り込み前後を撮る

1. コンテンツタイプを「画像のみ」にする。
2. 最低いいね数を「指定なし」にし、6 件が集計されていることを確認して撮影する。
3. 最低いいね数を 2,000 にし、3 件が残ることを確認して撮影する。そら・はる・なつの各 1 投稿が残る構成になる。
4. ページと実際の Sift パネル本体をそれぞれ取得する。OS の画面全体や、前面のアプリを撮影しない。

サイドパネルの件数とページ上の表示件数を照合する。絞り込みの前後で投稿データ、スクロール位置、表示倍率、描画領域の寸法を揃える。

## 掲載画像にまとめる

1280×800 ピクセルの白い背景へ、ページとパネルを並べる。外周の余白は上下左右とも 12 ピクセルにする。ページは角丸 10 ピクセルの枠と薄い影で囲い、パネル側の白い背景へ自然につなげる。

CDP で取得したパネル本体には Chrome が描く見出し部分が含まれないため、40 ピクセル分の領域に Sift の 16 ピクセルアイコンとアプリ名を補う。パネル本体の操作 UI は描き直さない。

左下に「※ 架空の投稿です」を入れる。今回の注記は Noto Sans JP、16 ピクセル、ウェイト 400、文字色 `#536471` とした。文字が潰れていないことを原寸で確認する。

画像生成 AI による描き直しは行わない。取得後の処理は縮小、配置、外枠、パネル見出し、注記の追加とする。

## 確認と終了

- 元の投稿画像、アカウント情報、認証バッジが残っていない。
- アイコンは元投稿の丸い形を使い、UI のフォントや操作アイコンを自作していない。
- 絞り込み後に 3 アカウントの投稿が一画面に収まり、Sift の条件と件数が読める。
- サイドカラムが写らず、文字の欠けや横スクロールバーがない。
- 四隅の余白、ページの枠、パネルとの境界、スクロールバーが自然に見える。

撮影後は拡張機能設定を復元し、対象タブと撮影用 Chrome を終了する。失敗時も終了処理を実行し、CDP の待受を残さない。

採用前の画像はプレビューとして保管する。採用後に正式な掲載画像へ反映し、README の件数・しきい値・作成方法も更新してコミットする。

# sift 操作デモ

ローカルでの閲覧と動画作成に使う、AstroとCSSで構築した操作デモです。デモの再生には小さなJavaScriptを使用します。配色と共通部品の見た目はshadcn/uiの標準スタイルに揃えています。

## 開発

Node.js 24.12 以降と pnpm 12.11.2 を使います。依存パッケージは拡張機能とまとめて管理し、ビルド成果物は別々に生成します。次のコマンドをリポジトリのルートから実行してください。

```sh
pnpm install --frozen-lockfile
cd website
pnpm run dev
```

開発サーバーが起動したら、表示されたURLの `/sift/` をブラウザーで開いてください。
`/sift/alternative/` でもメインページと同じデザインを表示します。

```sh
pnpm run check
pnpm run build
```

`check` は Astro と TypeScript でコードを検査します。`build` は静的ファイルを `dist/` に生成し、画像などの参照先、ページ内リンク、GitHub ボタンのスタイルを検査します。

## 操作デモとクレジット

操作デモでは、架空の投稿を使って X・Bluesky の絞り込み操作を紹介します。アイコン、パネル、条件選択、絞り込みの各段階をクリックして再生位置を変更できます。デモは繰り返し再生します。設定や操作は保存しません。

画像の作者と出典は、ページ下部から開けるクレジットページに掲載します。使用する素材の記録は [画像素材の記録](IMAGE-CREDITS.md)をご覧ください。

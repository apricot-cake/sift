# Sift

Sift は、X、Bluesky、Misskey のタイムラインに表示された投稿と YouTube の動画を、ブラウザ内で絞り込む Chrome 拡張です。

> [!WARNING]
> **Sift はリリース前です。** Chrome ウェブストアでは配布していません。利用するには、このリポジトリからビルドして拡張機能を読み込む必要があります。互換性のない変更により、保存した設定が初期値に戻ることがあります。対応サービスの画面構造が変わった場合は、更新されるまで判定できません。

## 設定

対応する画面で拡張機能のアイコンを押すと、ブラウザのサイドパネルで条件を変更できます。変更はすぐに画面へ反映されます。サイト全体の一時停止と個別フィルターの有効・無効は、サイトごとに保存します。

フィルターの切り替えは、任意で `chrome://extensions/shortcuts` からショートカットキーにも割り当てられます。

- 反応数: 1,000 いいね以上の投稿。Misskey では 20 リアクション以上の投稿
- リポストを除外
- YouTube: 10,000 回以上再生された動画

反応数と再生回数の初期設定は、投稿時期を制限しません。「期間を指定」に切り替えると、公開からの時間、日、週、月、または年と最低反応数を一組の条件として指定できます。各条件は個別に無効化できます。メディア条件とキーワード除外は初期状態では無効です。サイドパネルには、そのサービスで使える条件だけを表示します。

## インストール

Node.js 24.12 以降を用意して、次のコマンドを実行します。

```powershell
npm install
npm run deploy
```

`chrome://extensions` を開き、`.output\chrome-mv3` を「パッケージ化されていない拡張機能」として読み込みます。青い線は反応数または再生回数の条件に一致した項目を示します。フィルターの切り替えと条件の調整は拡張機能のアイコンから行います。

`.output\chrome-mv3` には検証済みのリリースビルドだけを配置します。開発ビルドはこのディレクトリに出力しません。

## 仕組みと制約

- 表示中の画面に読み込まれた投稿だけを判定します。自動スクロール、バックグラウンドでの収集、非公式 API の呼び出しは行いません。
- 投稿データは保存・送信しません。設定値だけを Chrome の同期ストレージに保存します。
- 非公開投稿、ブロック、地域制限などで画面に表示されない投稿は判定できません。
- 表示言語は、ブラウザの言語設定に従います。対応言語は英語、日本語、韓国語、繁体字中国語、簡体字中国語、スペイン語、ブラジルポルトガル語です。対応していない言語では英語を表示します。拡張機能で表示言語は切り替えられません。

### 対応サービス

判定条件はサイトごとに保存します。

| | X | Bluesky | Misskey | YouTube |
| --- | --- | --- | --- | --- |
| 対象ホスト | `x.com` / `twitter.com` | `bsky.app` | `misskey.io` | `www.youtube.com` |
| 指標 | いいね | いいね | 絵文字ごとのリアクションの合計 | 累計再生回数 |
| 投稿時期 | 全期間、または公開からの期間を指定 | 全期間、または公開からの期間を指定 | 全期間、または公開からの期間を指定 | 全期間、または公開からの期間を指定 |
| 除外する再投稿 | リポスト | リポスト | リノート | なし |

YouTube では、検索結果、登録チャンネルのフィード、チャンネルの動画タブとショートタブを判定します。ホーム、視聴ページの関連動画、再生リスト、履歴、ライブ配信は対象外です。期間を指定したときに公開時期を読み取れない動画と、累計再生回数を読み取れない項目は隠しません。

Bluesky では、ホーム、プロフィール、フィード、リスト、投稿詳細を判定します。通知画面では投稿の行だけを判定します。検索結果は対象外です。

Bluesky の投稿時刻は投稿 URL から読み取ります。読み取れない場合、全期間の判定は続けます。期間指定の判定では、その投稿を隠しません。リポストは画面上の文言ではなく構造から判定します。Bluesky の構造が変わった場合は、リポストを除外できなくなることがあります。

Misskey では、ホーム、ノート検索結果、ユーザーリスト、アンテナを判定します。ローカル、ソーシャル、グローバル、メディア、チャンネルは対象外です。

Misskey の画面は、判定に使える安定した目印が限られています。クラス名はビルドごとに変わるため、Sift はノートの構造から情報を読み取ります。画面構造が変わった場合は、正しく判定できないことがあります。

- リアクション数は、絵文字ごとのチップの合計です。総数は画面に常に表示されません。チップは 16 種類まで表示されるため、それより多くの種類が付いたノートは実際より少なく数えます。
- 投稿時刻は、画面に表示されたローカライズ済みの文字列から読み取ります。読み取れない言語でも全期間の判定は続けます。期間指定の判定では、そのノートを隠しません。
- リノートは除外します。引用リノートは本文を伴う投稿として扱うため、除外しません。
- メディアは、アバター、カスタム絵文字、ロールバッジを除く画像と動画です。閲覧注意やデータセーバーで表示されない添付も、メディアとして扱います。

## 新しい言語を追加する

文言は `locales/<言語>.yml` にあります。現在は `en`、`ja`、`ko`、`zh-TW`、`zh-CN`、`es`、`pt-BR` に対応しています。言語を追加するときは、翻訳ファイルと `locales/locales.test.ts` の `TARGET_LOCALES` を同時に更新します。

既存言語の訳を修正・補完するプルリクエストを歓迎します。`locales/<言語>.yml` を編集し、`npm test` を通してから送ってください。新しい言語を追加する提案は、先に Issue で相談してください。承認後に、翻訳ファイルと `TARGET_LOCALES` を更新します。

日本語以外の訳は AI による初期訳です。各言語の話者による修正や置き換えを歓迎します。AI による下書きも受け付けますが、マージ前にネイティブスピーカーまたは話者コミュニティのレビューを受けます。

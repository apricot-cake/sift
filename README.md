# Sift

X、Bluesky、YouTube、ニコニコ動画の投稿を、反応数、再生数、コンテンツタイプなどで絞り込むChrome拡張機能です。

## インストール

[Chrome ウェブストア](https://chromewebstore.google.com/detail/sift/jglehalaegleehefcefnfmmbblgkomeh)

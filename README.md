# sift

X・Blueskyでイラストを探すための Chrome 拡張機能です。いつものタイムラインやリストから、条件に合う投稿をサイドパネルへ集めます。

## 主な機能

- いいね数、画像・動画の有無、返信・引用・リポストの除外条件で投稿を絞り込めます。
- 投稿の本文と画像をパネル内で確認できます。
- 投稿をクリックすると、該当する投稿を新しいタブで開きます。
- スクロールで読み込まれた投稿を、同じ一覧内で最大1,000件まで保持します。
- パネルの末尾から続きを読み込めます。
- 絞り込み条件はサイトごとに保存します。

元ページの投稿を隠したり並べ替えたりせず、読み取った投稿をパネル内で絞り込みます。画像の内容からイラストかどうかを判定する機能はありません。

## インストール

[Chrome ウェブストア](https://chromewebstore.google.com/detail/sift/jglehalaegleehefcefnfmmbblgkomeh)からインストールします。

バージョンごとの変更内容は [Releases](https://github.com/apricot-cake/sift/releases) を参照してください。

## 使い方

1. X または Bluesky の対応するタイムラインやリストを開きます。
2. Chrome のツールバーで sift のアイコンを押し、サイドパネルを開きます。
3. 「絞り込み条件」タブで、最低いいね数、コンテンツタイプ、除外条件を選びます。
4. 「投稿」タブで結果を確認します。投稿をクリックすると、新しいタブで開きます。

条件は自動で保存されます。元の一覧タブへ戻ると、そのタブのパネルが再表示されます。サイドパネルに未接続と表示された場合は、投稿を取得するページのタブで sift のアイコンを押してください。

「投稿」タブの末尾へスクロールするか、追加読み込みのボタンを押すと、1回分だけ続きを読み込みます。読み込み中は元ページを一時的にスクロールし、取得後に閲覧位置を戻します。新しい投稿を取得できなかった場合は、自動で読み進めずに停止します。

絞り込みはブラウザー内で行います。投稿の内容を開発者へ送信しません。設定の同期など、扱うデータの詳細は [プライバシーポリシー](PRIVACY.md) をご覧ください。

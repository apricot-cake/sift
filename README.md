# Sift

Sift は、X、Bluesky、Misskey のタイムラインに表示された投稿を、ブラウザ内で絞り込む Chrome 拡張です。

> [!WARNING]
> **Sift はリリース前です。** Chrome ウェブストアでは配布していません。利用するには、このリポジトリからビルドして拡張機能を読み込む必要があります。互換性のない変更により、保存した設定が初期値に戻ることがあります。対応サービスの画面構造が変わった場合は、更新されるまで判定できません。

## 設定

初期設定は次のとおりです。対応するタイムラインを開いた状態で、拡張機能のアイコンから「ライブ調整を開く」を選ぶと、ブラウザのサイドパネルで条件を変更できます。変更はすぐにタイムラインへ反映されます。フィルターの有効・無効は、同じポップアップで切り替えます。切り替えは表示中のホストだけに保存されます。

フィルターの切り替えは、任意で `chrome://extensions/shortcuts` からショートカットキーにも割り当てられます。

- 通常: 画像または動画があり、いいねが 500 件以上の投稿。Misskey ではリアクションが 20 件以上の投稿
- 上昇中: 画像または動画があり、投稿から 6 時間以内で、いいねが 100 件以上の投稿。Misskey ではリアクションが 5 件以上の投稿
- リポストを除外

タイムラインの設定には、そのサービスで使うしきい値だけを表示します。

## インストール

Node.js 24.12 以降を用意して、次のコマンドを実行します。

```powershell
npm install
npm run deploy
```

`chrome://extensions` を開き、`.output\chrome-mv3` を「パッケージ化されていない拡張機能」として読み込みます。X または Bluesky で投稿が並ぶ画面を開くと、青い線は通常、橙色の線は上昇中の投稿を示します。フィルターの切り替えとライブ調整は拡張機能のアイコンから行います。

Misskey を使う場合は、拡張機能のアイコンから「インスタンスを管理」を開き、先にインスタンスを追加します。

`.output\chrome-mv3` には検証済みのリリースビルドだけを配置します。開発ビルドはこのディレクトリに出力しません。

## 仕組みと制約

- 表示中の画面に読み込まれた投稿だけを判定します。自動スクロール、バックグラウンドでの収集、非公式 API の呼び出しは行いません。
- 投稿データは保存・送信しません。設定値だけを Chrome の同期ストレージに保存します。
- 非公開投稿、ブロック、地域制限などで画面に表示されない投稿は判定できません。
- 表示言語は、ブラウザの言語設定に従います。対応言語は英語、日本語、韓国語、繁体字中国語、簡体字中国語、スペイン語、ブラジルポルトガル語です。対応していない言語では英語を表示します。拡張機能で表示言語は切り替えられません。

### 対応サービス

判定条件はサービス間で共有します。X と Bluesky では同じ「いいね数」のしきい値を使います。Misskey のリアクション数には、別のしきい値を使います。インスタンスの規模が大きく異なるためです。

| | X | Bluesky | Misskey |
| --- | --- | --- | --- |
| 対象ホスト | `x.com` / `twitter.com` | `bsky.app` | 追加したインスタンス |
| 反応の数 | いいね | いいね | 絵文字ごとのリアクションの合計 |
| しきい値 | いいね数 | いいね数（X と共有） | リアクション数（専用） |
| 除外する再投稿 | リポスト | リポスト | リノート |

Bluesky では、ホーム、プロフィール、フィード、リスト、投稿詳細を判定します。通知画面では投稿の行だけを判定します。検索結果は対象外です。

Bluesky の投稿時刻は投稿 URL から読み取ります。読み取れない場合は、上昇中の判定だけを行いません。通常の判定は続けます。リポストは画面上の文言ではなく構造から判定します。Bluesky の構造が変わった場合は、リポストを除外できなくなることがあります。

### Misskey インスタンスを追加する

Misskey は利用するインスタンスが人によって異なるため、追加したインスタンスだけにアクセスします。「インスタンスを管理」でホスト名（例: `misskey.io`）を追加すると、Chrome がそのホストへのアクセス許可を確認します。許可すると、そのホストにだけ content script を登録します。削除すると、登録とアクセス許可を解除します。

追加したホストが Misskey ではない場合、Sift は何もしません。投稿を判定する前に、そのページが Misskey であることを確認します。

Misskey の画面は、判定に使える安定した目印が限られています。クラス名はビルドごとに変わるため、Sift はノートの構造から情報を読み取ります。フォークやバージョンで構造が異なる場合は、正しく判定できないことがあります。

- リアクション数は、絵文字ごとのチップの合計です。総数は画面に常に表示されません。チップは 16 種類まで表示されるため、それより多くの種類が付いたノートは実際より少なく数えます。
- 投稿時刻は、画面に表示されたローカライズ済みの文字列から読み取ります。読み取れない言語では、上昇中の判定だけを行いません。通常の判定は続けます。
- リノートは除外します。引用リノートは本文を伴う投稿として扱うため、除外しません。
- メディアは、アバター、カスタム絵文字、ロールバッジを除く画像と動画です。閲覧注意やデータセーバーで表示されない添付も、メディアとして扱います。

## 新しい言語を追加する

文言は `locales/<言語>.yml` にあります。現在は `en`、`ja`、`ko`、`zh-TW`、`zh-CN`、`es`、`pt-BR` に対応しています。言語を追加するときは、翻訳ファイルと `locales/locales.test.ts` の `TARGET_LOCALES` を同時に更新します。

既存言語の訳を修正・補完するプルリクエストを歓迎します。`locales/<言語>.yml` を編集し、`npm test` を通してから送ってください。新しい言語を追加する提案は、先に Issue で相談してください。承認後に、翻訳ファイルと `TARGET_LOCALES` を更新します。

日本語以外の訳は AI による初期訳です。各言語の話者による修正や置き換えを歓迎します。AI による下書きも受け付けますが、マージ前にネイティブスピーカーまたは話者コミュニティのレビューを受けます。

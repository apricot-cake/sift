# Sift

Sift は、対応するサービスの一覧画面から、設定した条件を満たす投稿だけを残す Chrome 拡張機能です。X、Bluesky、Misskey、YouTube、ニコニコ動画、SoundCloud を、サービスごとの反応数、再生数、公開時期、メディア、キーワードなどで判定します。

判定には、ブラウザに表示された情報だけを使います。投稿データの保存や送信、非公式 API による収集は行いません。

# 対応サービス

sift は、X・Blueskyの画面に読み込まれた投稿をサイドパネルへ集め、条件に合う投稿を表示します。ツールバーのアイコンを押したタブが対象です。投稿のリンクは新しいタブで開きます。

「投稿」タブで本文と画像を確認し、「絞り込み条件」タブで条件を変更できます。タブを切り替えても条件と収集結果を保持します。

パネル末尾へのスクロールや追加読み込みボタンの操作に応じて、元ページを一時的に進めて投稿を収集し、閲覧位置を戻します。1回の操作で読み込む量と待機時間には上限があり、条件に合う投稿が出るまで自動で読み進めることはありません。取得に失敗した場合や、サイトの利用制限・認証要求を検出した場合は停止します。X・BlueskyのAPIは直接呼び出しません。

非公開、ブロック、地域制限などにより表示されない投稿は取得できません。同じ一覧内で最大1,000件を一時保持し、条件を変えると保持した投稿へ適用します。

上限に達した後も、収集済みの投稿のいいね数などは更新します。パネルを手動で閉じて開くと、現在のページから収集し直します。別タブへ移動して戻るだけでは収集結果を消しません。

## 対応範囲

| サービス | 対象ホスト | 指標 | 主な対象画面 |
| --- | --- | --- | --- |
| X | `x.com` / `twitter.com` | いいね数 | フォロー中、固定リスト、リスト専用ページ、検索（最新のみ）、プロフィールの「ポスト」 |
| Bluesky | `bsky.app` | いいね数 | ホームのすべてのフィード、リスト専用ページ、フィード専用ページ、検索（最新のみ）、プロフィールの「投稿」「メディア」「ビデオ」 |

## 投稿の判定に関する制約

X のプロフィールは「ポスト」タブだけが対象です。返信・リポスト・動画・画像・ハイライト・いいねなど、その他のタブは対象外です。

X の一覧にある、投稿リンクのない広告は収集しません。

X の対応一覧から画像や動画を拡大した場合は、元の一覧の設定と収集済み投稿を保ちます。個別投稿や画像の URL を直接開いた場合は対象外です。

Bluesky のプロフィールは「投稿」「メディア」「ビデオ」タブが対象です。「返信」など、その他のタブは対象外です。

Bluesky のホームでは、Discover、フォロー中、固定リスト、カスタムフィードを対象とします。専用ページは `/profile/<actor>/lists/<rkey>` と `/profile/<actor>/feed/<rkey>` が対象です。

元ページの投稿を隠す処理は行いません。対象外ページでは収集しません。X のおすすめ・個別投稿、Bluesky の個別投稿は対象外です。元の一覧を離れるとパネルを閉じます。

いいね数を指定した場合、いいね数を読み取れない投稿はパネル内の結果から除外します。「指定なし」では表示します。画像の内容からイラストかどうかを自動判定する機能はありません。対応サービスの画面構造が変わると、sift の更新まで投稿を正しく取得できない場合があります。

# 対応サービス

Sift は、ユーザーがツールバーのアイコンを押した現在のタブで、画面に読み込まれた投稿をサービスごとのアダプターで読み取り、同じフィルター処理へ渡します。自動スクロールやバックグラウンドでの収集は行いません。ページを移動した後は、もう一度 Sift を開く必要があります。非公開、ブロック、地域制限などで表示されない投稿は判定できません。

## 対応範囲

| サービス | 対象ホスト | 指標 | 主な対象画面 |
| --- | --- | --- | --- |
| X | `x.com` / `twitter.com` | いいね数 | ホーム、フォロー中、リスト、プロフィール、検索結果、投稿詳細 |
| Bluesky | `bsky.app` | いいね数 | ホーム、プロフィール、フィード、リスト、投稿詳細、通知内の投稿 |
| YouTube | `www.youtube.com` | 再生回数、公開から指定期間以内の動画、メンバー限定動画の除外 | 検索結果、登録チャンネル、チャンネルの動画・ショート、チャンネル内検索 |
| ニコニコ動画 | `www.nicovideo.jp` | 再生回数、公開から指定期間以内の動画の除外 | 検索、タグ、ユーザーの動画・マイリスト |

## 投稿の判定に関する制約

X の投稿詳細では、URL が指す当該投稿を絞り込み条件に関係なく表示します。返信など、同じ画面に並ぶ他の投稿には引き続きフィルターを適用します。リストへ戻ると、そのリストの投稿にも再びフィルターを適用します。

指標を画面から読み取れない投稿は隠しません。たとえば、メンバー限定動画などでカードに再生数が表示されない場合は、最低再生数の条件では非表示にしません。対応サービスの画面構造が変わった場合は、アダプターを更新するまで判定できないことがあります。

YouTube の「メンバー限定を除外」は、カードに表示されたメンバー限定バッジだけで判定します。動画の視聴権限や会員状態は読み取りません。

YouTube のホーム、視聴ページの関連動画、再生リスト、履歴、ライブ配信は対象外です。

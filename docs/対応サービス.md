# 対応サービス

sift は、ユーザーがツールバーのアイコンを押した現在のタブで、画面に読み込まれた投稿をサービスごとのアダプターで読み取り、同じフィルター処理へ渡します。バックグラウンドでの収集は行いません。パネルを開いたままページを移動すると、対応状況を更新します。非公開、ブロック、地域制限などで表示されない投稿は判定できません。

## 対応範囲

| サービス | 対象ホスト | 指標 | 主な対象画面 |
| --- | --- | --- | --- |
| X | `x.com` / `twitter.com` | いいね数 | フォロー中、固定リスト、リスト専用ページ、検索（最新のみ）、プロフィールの「ポスト」 |
| Bluesky | `bsky.app` | いいね数 | ホームのすべてのフィード、リスト専用ページ、フィード専用ページ、検索（最新のみ）、プロフィールの「投稿」「メディア」「ビデオ」 |
| YouTube | `www.youtube.com` | 投稿期間 | チャンネルの動画・配信（人気の動画のみ） |
| ニコニコ動画 | `www.nicovideo.jp` | 投稿期間 | ユーザーの投稿動画一覧とキーワード検索（再生数が多い順のみ） |

## 投稿の判定に関する制約

X のプロフィールは「ポスト」タブだけが対象です。返信・リポスト・動画・画像・ハイライト・いいねなど、その他のタブは対象外です。

X の対応一覧から画像や動画を拡大した場合は、元の一覧のフィルター設定と集計を保ちます。拡大表示中の投稿は絞り込みません。個別投稿や画像の URL を直接開いた場合は対象外です。

Bluesky のプロフィールは「投稿」「メディア」「ビデオ」タブが対象です。「返信」など、その他のタブは対象外です。

Bluesky のホームでは、Discover、フォロー中、固定リスト、カスタムフィードを対象とします。専用ページは `/profile/<actor>/lists/<rkey>` と `/profile/<actor>/feed/<rkey>` が対象です。

対象外ページではフィルターを適用しません。対象ページから移動した場合も、非表示状態を解除します。X のおすすめ・個別投稿、Bluesky の個別投稿は対象外です。

いいね数や公開時期を読み取れない投稿は、その条件では隠しません。対応サービスの画面構造が変わった場合は、アダプターを更新するまで判定できないことがあります。

YouTube の「人気の動画」とニコニコ動画の「再生数が多い順」では、「投稿期間」で指定期間以内に公開された動画へ絞り込みます。サイトの並び順は変更しません。期間の指定はサイトごとに保存します。

YouTube の新しい順・古い順・並び順の選択欄がない一覧、ショート、チャンネル内検索、ホーム、サイト全体の検索、登録チャンネル、視聴ページ、再生リスト、履歴は対象外です。ニコニコ動画の新しい順・その他の並び順、タグ検索、マイリストは対象外です。

# 対応サービス

Sift は、ユーザーがツールバーのアイコンを押した現在のタブで、画面に読み込まれた投稿をサービスごとのアダプターで読み取り、同じフィルター処理へ渡します。バックグラウンドでの収集は行いません。パネルを開いたままページを移動すると、対応状況を更新します。非公開、ブロック、地域制限などで表示されない投稿は判定できません。

## 対応範囲

| サービス | 対象ホスト | 指標 | 主な対象画面 |
| --- | --- | --- | --- |
| X | `x.com` / `twitter.com` | いいね数 | フォロー中、固定リスト、リスト専用ページ、検索（最新のみ）、プロフィールの「ポスト」 |
| Bluesky | `bsky.app` | いいね数 | フォロー中、固定リスト、リスト専用ページ、検索（最新のみ）、プロフィールの「投稿」「メディア」「ビデオ」 |
| YouTube | `www.youtube.com` | 再生回数、公開期間、メンバー限定動画の除外（ショートは公開期間に非対応） | チャンネルの動画・ショート・配信（新しい順・人気の動画のみ）、チャンネル内検索 |
| ニコニコ動画 | `www.nicovideo.jp` | 再生回数、公開から指定期間以内の動画の除外 | ユーザーの投稿動画一覧（投稿日時が新しい順・再生数が多い順のみ） |

## 投稿の判定に関する制約

X のプロフィールは「ポスト」タブだけが対象です。返信・リポスト・動画・画像・ハイライト・いいねなど、その他のタブは対象外です。

Bluesky のプロフィールは「投稿」「メディア」「ビデオ」タブが対象です。「返信」など、その他のタブは対象外です。

対象外ページではフィルターを適用しません。対象ページから移動した場合も、非表示状態を解除します。X のおすすめ・個別投稿、Bluesky のカスタムフィード・個別投稿は対象外です。

指標を画面から読み取れない投稿は隠しません。たとえば、メンバー限定動画などでカードに再生数が表示されない場合は、最低再生数の条件では非表示にしません。対応サービスの画面構造が変わった場合は、アダプターを更新するまで判定できないことがあります。

YouTube の「メンバー限定を除外」は、カードに表示されたメンバー限定バッジだけで判定します。動画の視聴権限や会員状態は読み取りません。

YouTube の「人気の動画」とニコニコ動画の「再生数が多い順」では、「再生回数の上限」を指定できます。スイッチをオンにすると上限を超える動画を非表示にします。上限と同じ回数の動画や、再生数が不明な動画は残します。ほかの並び順では適用しません。入力値とスイッチの状態はサイトごとに保存します。

YouTube のホーム、検索、登録チャンネル、視聴ページ、再生リスト、履歴は対象外です。ニコニコ動画の検索、タグ検索、マイリストも対象外です。

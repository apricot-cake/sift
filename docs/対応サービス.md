# 対応サービス

Sift は、画面に読み込まれた投稿をサービスごとのアダプターで読み取り、同じフィルター処理へ渡します。自動スクロールやバックグラウンドでの収集は行いません。非公開、ブロック、地域制限などで表示されない投稿は判定できません。

## 対応範囲

| サービス | 対象ホスト | 指標 | 主な対象画面 |
| --- | --- | --- | --- |
| X | `x.com` / `twitter.com` | いいね数 | ホーム、フォロー中、リスト、プロフィール、検索結果、投稿詳細 |
| Bluesky | `bsky.app` | いいね数 | ホーム、プロフィール、フィード、リスト、投稿詳細、通知内の投稿 |
| YouTube | `www.youtube.com` | 再生回数 | 検索結果、登録チャンネル、チャンネルの動画・ショート |
| ニコニコ動画 | `www.nicovideo.jp` | 再生回数 | 検索、タグ、ユーザーの動画・マイリスト |

## 投稿の判定に関する制約

指標や公開時期を画面から読み取れない投稿は隠しません。対応サービスの画面構造が変わった場合は、アダプターを更新するまで判定できないことがあります。

Bluesky の投稿時刻は投稿 URL から読み取ります。

YouTube のホーム、視聴ページの関連動画、再生リスト、履歴、ライブ配信は対象外です。
